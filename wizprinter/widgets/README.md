# `wizprinter/widgets/` — reusable UI widgets

Shared Kivy widgets used by multiple screens. Their visual layout is defined in
[`kv/widgets.kv`](../../kv/widgets.kv).

| File | Widget |
|------|--------|
| `statusbar.py` | `StatusBar` — top bar with Back/Home button (history-based navigation), title, and Wi-Fi indicator. Sets the Back button's spoken accessibility label. |
| `bottomnav.py` | `BottomNav` — bottom tab bar (Home / Docs / Scan / Settings). |

See each module's top-of-file docstring for detail.
